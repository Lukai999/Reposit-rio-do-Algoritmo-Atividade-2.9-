# Repositorio-do-Algoritmo-Atividade-2.9-
Este repositório contém a implementação de duas abordagens para o cálculo de polinômios, contida no arquivo "main.cpp".
A implementação visa atender os seguintes topicos:
1. **Versão O(n²)**: Implementação simples com potências iterativas.
2. **Versão O(n)**: Implementação eficiente usando a Regra de Horner.
